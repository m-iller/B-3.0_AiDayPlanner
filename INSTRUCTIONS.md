# AI Day Planner — Installation & Startup

## Requirements

- Python 3.11+
- pip

---

## Installation

### 1. Clone the repository

```bash
git clone <repo-url>
cd ai-day-planner
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it:

- **Linux / macOS:**
  ```bash
  source .venv/bin/activate
  ```
- **Windows (CMD):**
  ```cmd
  .venv\Scripts\activate.bat
  ```
- **Windows (PowerShell):**
  ```powershell
  .venv\Scripts\Activate.ps1
  ```

### 3. Install dependencies

```bash
pip install -e .
```

To also install dev/test dependencies:

```bash
pip install -e ".[dev]"
```

## Configuration

All configurable values live in `config/default.toml`. No code changes are needed to tune behavior — edit the TOML file instead.

Key sections:

| Section       | Controls                                              |
|---------------|-------------------------------------------------------|
| `[task]`      | Difficulty / urgency / importance ranges              |
| `[calendar]`  | Active hours (start / end)                            |
| `[fatigue]`   | Score bounds, increase/recovery weights, penalty      |
| `[scheduler]` | Priority weights, probability threshold, overload cap |
| `[learning]`  | EMA smoothing factor, default correction coefficient  |
| `[probability]`| Prior probability, per-factor weights               |
| `[logging]`   | Log level (`DEBUG` / `INFO` / `WARNING` / `ERROR`)    |

To use a custom config file, pass its path when starting the server (see below).

## Starting the Server

### Default (uses `config/default.toml`, in-memory SQLite)

```bash
uvicorn ai_day_planner.main:create_app --factory --reload
```

### Custom config path

Set the `CONFIG_PATH` environment variable before starting:

```bash
CONFIG_PATH=config/default.toml uvicorn ai_day_planner.main:create_app --factory --reload
```

> **Note:** The app currently uses an in-memory SQLite database by default. Data does not persist across restarts. To wire a file-based DB, modify the `get_connection` call in `main.py` to point to a file path (e.g. `planner.db`).

### Production (no reload)

```bash
uvicorn ai_day_planner.main:create_app --factory --host 0.0.0.0 --port 8000
```

## API

Base URL: `http://localhost:8000/api/v1/`

Interactive docs (auto-generated by FastAPI):

- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

All responses follow the envelope schema:

```json
{ "data": <value or null>, "error": null }          // success
{ "data": null, "error": { "code": "...", "message": "...", "details": ... } }  // failure
```

## Project Structure

```
ai_day_planner/        # Application source
  main.py              # App factory (create_app)
  config.py            # Config loader (TOML → dataclasses)
  database.py          # SQLite connection + migrations
  event_bus.py         # In-process pub/sub
  logger.py            # Structured JSON logger
  modules/
    tasks/             # Task CRUD + domain logic
    calendar/          # Time blocks + free slot computation
    scheduler/         # Priority scoring + slot assignment
    fatigue/           # Fatigue score tracking
    time_tracker/      # Session recording + interruptions
    learning/          # EMA correction coefficients
    probability/       # Completion probability model
    shared/            # API envelope + shared exceptions

config/
  default.toml         # All configurable values

tests/
  unit/                # Pure function tests
  integration/         # DB + service layer tests
  property/            # Hypothesis property-based tests
```

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `ConfigurationError` on startup | Missing or invalid field in TOML | Check `config/default.toml` against the schema in `config.py` |
| `ModuleNotFoundError` | Package not installed | Run `pip install -e .` |
| Port already in use | Another process on 8000 | Use `--port <other>` flag |
| Tests fail with import errors | Dev deps missing | Run `pip install -e ".[dev]"` |
